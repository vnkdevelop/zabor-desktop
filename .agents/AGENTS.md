# Workspace Rules for Zabor Desktop

- **ОБЯЗАТЕЛЬНАЯ РАБОТА С ГРАФАМИ (Graphify)**:
  1. Перед анализом файлов кода для любых задач агент ОБЯЗАН СНАЧАЛА обратиться к графам знаний (`graphify-out/graph.json`, `graphify query`, `graphify path`, `graphify explain` или `graphify-out/GRAPH_REPORT.md`), чтобы мгновенно понять структуру, связи и расположение нужных компонентов без лишнего расхода токенов.
  2. Все изменения в проекте должны быть структурированы в графах приложений.
  3. После ВСЕХ изменений в коде или файлах проекта агент ОБЯЗАН обновлять граф знаний (`graphify update .` или `graphify extract . --code-only`).
